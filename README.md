#

# !\[PHP Version](https://img.shields.io/badge/PHP-8.0%2B-777bb3)

# 

# \*\*Bulk Plugin Installation\*\* is an improved WordPress plugin installation tool that allows you to install one or more plugins simply by typing their names or download URLs in a textarea.

# 

# Maintained and updated by \*\*\[Bee Web Hosting](https://www.beewh.com)\*\*.

# 

# \## ✨ Features

# \* \*\*Bulk Installation\*\*: Install multiple plugins at once, saving you time.

# \* \*\*Flexible Input\*\*: Accepts plugin slugs, WordPress.org repository URLs, or direct ZIP file URLs.

# \* \*\*Modernized\*\*: Fully rewritten (v2.0) to be compatible with PHP 8+ and WordPress 6.x/7.x.

# \* \*\*HTTPS Support\*\*: Fully supports modern secure URLs.

# 

# \## 🚀 Installation

# 

# 1\. Download the latest release or clone this repository.

# 2\. Upload the `bulk-plugin-installation` directory to your `/wp-content/plugins/` directory.

# 3\. Activate the plugin through the \*\*Plugins\*\* menu in WordPress.

# 

# \## 💡 Usage

# 

# 1\. Go to your WordPress Admin Dashboard.

# 2\. Navigate to \*\*Plugins\*\* \&raquo; \*\*Bulk Install\*\*.

# 3\. Paste your plugin names or URLs into the text area (one per line).

# 4\. Click \*\*Install now\*\*.

# 

# \### Input Examples

# The installation form accepts any of these formats:

# ```text

# woocommerce

# contact-form-7

# https://wordpress.org/plugins/contact-form-7/

# https://downloads.wordpress.org/plugin/contact-form-7.zip

# ```

# \*Note: Plugins don't need to be hosted at wordpress.org. As long as you use the direct download URL (ZIP), third-party plugins will install without a problem.\*
